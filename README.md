# Plaud 보강 작업대

Plaud 녹음의 빈 곳을 메우는 개인용 웹앱입니다. GitHub Codespaces에서 돌리고, 브라우저로 접속해 씁니다.

| 작업 | 하는 일 |
|---|---|
| **누락 구간 보충** | Plaud 전사가 녹음 중간에 끊겼을 때, 끊긴 지점부터 녹음 끝까지 전사하고 화자를 붙입니다. |
| **지정 구간 다시 전사** | 잘못 전사된 구간(시작~끝)만 다시 전사합니다. |
| **조각 음원 화자 매칭** | Plaud에 없는 음성, 여러 파일로 나뉜 같은 회의 녹음을 전사하고 저장된 목소리 기준으로 화자를 맞힙니다. |
| **목소리 기준만 등록** | Plaud 전사(화자 이름 포함)와 음원으로 사람별 목소리 기준만 만듭니다. |

처리 결과는 검수 화면에서 구간마다 들어 보며 화자·문장을 고치고, Plaud 전사와 합친 **통합본(TXT·CSV)** 으로 내려받습니다.

## 시작하기 (처음 한 번)

1. 이 저장소 화면에서 **Code → Codespaces → Create codespace on main**.
   - 4코어 머신이 자동으로 고정됩니다(`.devcontainer/devcontainer.json`).
2. 처음 만들 때 ffmpeg·파이썬 패키지 설치와 모델(Whisper turbo·CAM++, 약 1GB) 받기가 자동으로 돌아갑니다. 5~10분 걸립니다.
3. 끝나면 서버가 자동으로 켜지고 **「Plaud 보강 작업대」 포트(8765)** 가 브라우저 새 탭으로 열립니다.
   - 안 열리면 VS Code 아래 **포트** 탭에서 8765의 지구본 아이콘을 누르세요.
   - 서버가 꺼져 있으면 터미널에서 `bash scripts/start.sh`.
4. GitHub 설정 → **Codespaces → Default idle timeout을 240분**으로 올려 두세요. 처리 중에 Codespace가 멈추는 것을 막습니다(멈춰도 다시 열면 끊긴 구간부터 이어서 처리합니다).

두 번째부터는 [github.com/codespaces](https://github.com/codespaces)에서 만들어 둔 Codespace를 다시 열면 됩니다. 작업대 주소(`https://<이름>-8765.app.github.dev`)를 즐겨찾기해 두면, Codespace가 켜져 있을 때 바로 들어갈 수 있습니다.

## 쓰는 법

1. Plaud 웹/앱에서 녹음 음원(MP3)과 전사(**TXT·SRT·DOCX**, 타임스탬프·화자 표시 켜기)를 내보냅니다.
2. 작업대 **「새 작업」** 에서 유형을 고르고 음원과 전사 파일을 올립니다.
   - 전사를 올리면 전사가 녹음 어디서 끝나는지 띠로 보여줍니다.
   - 「Speaker 1」처럼 이름이 없는 화자는 실제 이름을 넣어 주세요. 이름을 넣은 사람만 목소리 기준으로 저장됩니다.
3. 작업 목록에서 진행률을 봅니다. 4코어 기준 30분 음성에 대략 20~40분(추정)이 걸립니다.
4. **검수·내보내기** 탭에서 「확인 필요」(화자 혼재·미상·저신뢰)부터 ▶로 들어 보고 고칩니다. 고친 내용은 자동 저장됩니다.
5. **통합본 TXT** 로 내려받아 회의록 작성에 씁니다.

## 데이터와 보안

- 음원·전사·목소리 기준·검수 내용은 Codespace 안의 `data/` 폴더에만 저장됩니다. `.gitignore`에 들어 있어 **저장소에는 올라가지 않습니다.**
- 작업대 주소는 본인 GitHub 계정으로만 열립니다(포트 공개 범위 Private). Public으로 바꾸지 마세요.
- 목소리 기준은 개인을 식별할 수 있는 정보입니다. 필요 없어진 사람은 「목소리 기준」 탭에서 지우세요.
- 다 쓴 작업은 「음원 지우기」로 음원만 지울 수 있습니다(결과는 남습니다).
- Codespace는 오래 쓰지 않으면(기본 30일) 지워집니다. **설정·백업 → 백업 내려받기**로 음원을 뺀 데이터를 받아 두고, 새 Codespace에서 「백업 올리기」로 되살립니다.

## 엔진

| | 쓰는 것 | 비고 |
|---|---|---|
| 전사 | sherpa-onnx Whisper turbo (int8) | 한글 글자 빠짐을 막는 바이트 복원 우회 적용, 25초 이하로 나눠 처리 |
| 화자 | CAM++ 목소리 특징 + 기준 맞히기 | Plaud가 이름 붙인 구간으로 사람별 기준을 만들고, 3초 창 투표로 판정(70% 이상 단일, 아니면 혼재) |
| 환각 제거 | 「다음 영상에서…」류·4자 이상 반복 | 자동으로 빼고 건수만 남김 |

시험 결과(2026. 10. 8. 실제 회의): 화자 맞히기 92.6% 일치, 3분 조각 음원을 저장된 기준만으로 처리해도 전체 처리와 판정이 같았습니다.

## 개발

```bash
pip install -r requirements-dev.txt
PB_FAKE_ENGINE=1 python -m pytest -q     # 모델 없이 전체 흐름 시험
python -m app.engine setup models        # 실제 모델 받기
python -m app.server                     # http://127.0.0.1:8765
```

환경 변수: `PB_DATA`(데이터 폴더), `PB_MODELS`(모델 폴더), `PB_PORT`, `PB_HOST`, `PB_FAKE_ENGINE=1`(가짜 엔진).
